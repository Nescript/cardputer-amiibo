# 《塞尔达传说：旷野之息 / 王国之泪》全套 Amiibo 测试数据包指南

本项目已通过 [`tools/fetch_amiibo.py`](../tools/fetch_amiibo.py) 从开源镜像库（`ryanshatch/Amiibo.dump` 与 `AmiiboDB/Amiibo`）拉取并校验了 **全部 34 个塞尔达系列 Amiibo**（覆盖 33 个独立官方角色模型 ID + 20 心 / 3 心两种狼林克存档）以及 **20 个通用素材掉落 Amiibo**，共 **54 个标准 540 字节 `.bin` 文件**，保存在本地 `sd_stage/amiibo/`。

将 `sd_stage/amiibo/` 下的子文件夹直接复制到 microSD 卡根目录的 **`/amiibo/`** 即可在 Cardputer-Adv 上浏览并刷卡。

---

## 1. 一键更新或扩展更多 Amiibo

```bash
# 下载完整 34 个塞尔达 Amiibo + 20 个通用素材掉落 Amiibo（共 54 个，已包含于 sd_stage/amiibo/）
python tools/fetch_amiibo.py --preset zelda-plus-bonus --bonus-count 20 --out sd_stage/amiibo

# 仅下载 34 个塞尔达 Amiibo
python tools/fetch_amiibo.py --preset zelda-full --out sd_stage/amiibo

# 需要更多通用素材掉落卡时（最多可从 ryanshatch/Amiibo.dump 1,039 份库中扩充）：
python tools/fetch_amiibo.py --preset zelda-plus-bonus --bonus-count 100 --out sd_stage/amiibo

# 按关键词单独搜索下载其他游戏角色
python tools/fetch_amiibo.py --search "Splatoon" --source ryanshatch --out sd_stage/amiibo --limit 15
```

> 《王国之泪》对同一张 Amiibo 有每日使用限制。Switch 2 固件的 `R` 和 `AUTO-RND` 需要先导入本地密钥。操作见[重复刷卡指南](FLASH_AND_TEST_GUIDE.md#switch-2-重复刷卡)。
